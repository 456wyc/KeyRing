你的账户数据，安全地握在手中

Key Ring 是一款开源、跨平台的桌面账户管理工具。基于 Electron + React 构建，AES 加密存储，主密码 PBKDF2 保护，完全离线运行。

⚡快速开始 ★前往 GitHub
核心能力

为账户管理而生的一站式工具

从密码生成到加密备份，覆盖账户管理的完整流程。

🔐

AES 加密存储

所有账户数据使用主密码派生的密钥进行 AES 加密，密钥永不落盘。

🔑

主密码管理

支持随时修改、取消或重新启用主密码，数据自动重新加密。

🏷️

标签系统

多标签分类、多选筛选、一致性配色，海量账户井然有序。

🎲

密码生成器

可自定义长度、字符类型与排除规则，一键生成强密码。

🗂️

自定义字段

除用户名密码外，可添加任意字段，支持拖拽排序与重命名。

💾

加密备份

导出加密备份文件，跨设备迁移或灾后恢复都简单可靠。

🌐

中英双语

完整翻译的界面，一键在中英文之间切换。

🖥️

跨平台桌面应用

基于 Electron 构建，Windows、macOS、Linux 全平台可用。

快速开始

三步启动

无需安装包，克隆仓库即可在本地运行。

1

安装依赖

克隆仓库后，在项目根目录安装 npm 依赖。

npm install
2

启动应用

构建并启动 Electron 应用（Windows 可直接双击 run.bat）。

npm run start
3

创建主密码

首次启动创建主密码，即可开始管理你的账户。

牢记主密码 · 无法找回
